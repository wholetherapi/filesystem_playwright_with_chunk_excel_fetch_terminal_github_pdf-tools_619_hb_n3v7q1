# Static Load Cells — certification requirements

- **Track ID:** SLC-02
- **Owner:** Static Load Cells Programme Office (SLC-PO)
- **Level:** track
- **Conformance profile:** RIC-SLC-1.9
- **Last revised:** 2025-12-02

## Minimum field validation

Applicants for the Static Load Cells track must document at least
**96 supervised field-validation hours** on a calibrated
static-load rig.

## Scope

This page applies to static load cell products only. It does not apply to
rotating equipment, flow meters or any other track.

## Evidence checklist

1. Field-validation log (RIC-LOG-09) covering the required hours.
2. Rig calibration certificate.
3. Quality-function countersignature.
4. Repeatability study across at least three load points.
5. Temperature-compensation report.

## Notes for reviewers

Reviewers should confirm that the submitted rig matches the load class declared
in the application. The programme office keeps a list of accepted rig models in
SLC-PO-04. Submissions that use a non-listed rig must include an equivalence
statement signed by the laboratory's technical manager. The statement must
identify the reference rig, the measured deviation, and the compensating
procedure applied. Where a submission relies on multiple rigs, the validation
hours are counted only for the periods during which the submitted build was
mounted on the rig. Unmounted transport time does not count. The programme
office has clarified this rule twice in the last eighteen months; the latest
clarification is recorded in SLC-PO-07 section 4.3. This paragraph is long on
purpose because track pages accumulate review guidance over time.
