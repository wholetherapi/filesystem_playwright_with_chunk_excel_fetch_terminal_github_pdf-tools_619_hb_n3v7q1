# RIC PBA Legacy SDK

**Maintainer:** RIC Legacy Programme (archive)

This is the **official SDK** published for **RIC-PBA-2.1**, the superseded
predictive-baseline profile.

The 2.1 profile has different field-validation rules from `RIC-PBA-2.4` and is
not equivalent to it. The programme office has retired 2.1 for new
certification submissions; packages targeting only `RIC-PBA-2.1` cannot be used
for a `RIC-PBA-2.4` submission.
