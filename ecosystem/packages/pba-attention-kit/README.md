# PBA Attention Kit

**Maintainer:** Open Modelling Labs

This package implements **PBA-Attention**, an attention-based
predictive-maintenance model family published as the separate research
specification `PBA-ATT-2601`.

It is not an implementation of any RIC conformance profile. In particular it
does not implement `RIC-PBA-2.4`; its data contract, calibration procedure and
evidence output differ from the RIC profile.
