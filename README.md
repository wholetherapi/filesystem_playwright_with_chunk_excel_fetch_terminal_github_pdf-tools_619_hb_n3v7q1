# Ravensworth Instrumentation Consortium — Handbook Portal

This public repository publishes the consortium's certification documentation and
the package registry snapshots used by member organisations.

## Repository layout

| Path | Purpose |
| --- | --- |
| `handbook/institution.json` | Organisational tree of the consortium and which unit owns which page |
| `handbook/site-search-index.json` | Index used by the handbook portal's site search |
| `handbook/pages/policies/` | Network-level policy pages |
| `handbook/pages/divisions/` | Division-level requirement pages |
| `handbook/pages/profiles/` | Track-level certification requirement pages |
| `handbook/pages/community/` | Member community Q&A mirrors (not normative) |
| `ecosystem/index.json` | Package registry snapshot for the current conformance profiles |
| `ecosystem/packages/` | Documentation published by each package maintainer |

## Working rules

* Requirements are published by the organisational unit that owns the scope in
  question (network, division or track).
* Community Q&A pages are mirrors of member discussions and are not normative.
* Certification records themselves are kept in the programme's records
  repository, not in this handbook.
